## 🧠 Universal AI Memory - Initial Release

**One unified memory system for all your AI coding assistants**

### ✨ Features

- **Unified Storage** - All AI work in one place (Claude Code & Codex CLI)
- **Automatic Extraction** - Hourly capture of conversations via LaunchAgents
- **Fast CLI** - Search and filter in <100ms
- **Cross-System Visibility** - See work from all AI assistants
- **One-Command Installer** - `./install.sh` does everything
- **100% Local** - Your data never leaves your machine
- **Session Integration** - Memory loads automatically in Claude Code

### 🚀 Quick Start

```bash
git clone https://github.com/Ironsail-Philip/universal-memory.git
cd universal-memory
./install.sh
```
